## [0.1.0] - 2026-09-24

### Added

- Responsive Textual process monitor with flat, tree, and hierarchical category views.
- Explainable deterministic tags, user overrides, and optional local Laya Core ML suggestions.
- Safe terminate, kill, pause, and resume controls with confirmation, ownership checks, ancestor protection, and PID-reuse defense.
- Search, sorting, pinning, details, action history, JSON snapshots, diagnostics, demo mode, and local performance benchmarks.
- macOS and Linux test matrix for Python 3.11–3.13, package smoke tests, and dependency update automation.

### Security

- Pinned model revision with an application-owned manifest checksum and per-file SHA-256 verification.
- Strict model-output schema, normalization, range, and argmax validation.
- Serialized, atomic, durable label updates across concurrent application instances.
